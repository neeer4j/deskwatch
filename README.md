# ⏱️ DeskWatch

A sleek Windows app that tracks how much time you spend in your apps. No cloud, no subscriptions — just clean, local tracking with a beautiful dark UI.

## 🚀 Getting Started

1. **Run the app** — You'll see a quick welcome screen on first launch
2. **Add apps** — Click "Add Application" to pick from running apps or browse for any `.exe`
3. **Track away** — It starts automatically and counts time for your whitelisted apps
4. **Check stats** — Click any app card to see detailed usage

> 💡 **Tip:** Close the window to minimize to tray. Right-click the tray icon to exit completely.

## ⚙️ Settings

Open Settings to:
- Toggle auto-start with Windows
- Enable/disable idle detection
- Export your data to JSON
- Import data from a backup
- Clear all tracking data

## 🛠️ Built With

- **WPF** on **.NET 10** — Modern Windows UI
- **Custom dark theme** — Easy on the eyes
- **Win32 APIs** — For accurate window tracking

## 📁 Where's My Data?

Everything stays on your machine:
```
%AppData%\DeskWatch\
├── settings.json    # Your preferences
└── usage_data.json  # Tracking data
```
